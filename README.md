# PhonePe Transactions Dashboard

## 📌 Project Overview
PhonePe is a leading digital payments platform in India, processing billions of transactions annually. This Power BI dashboard visualizes transaction data, helping stakeholders analyze trends, regional distribution, and growth over time.

## 🎯 Goals
- Develop a **comprehensive** dashboard for key transaction metrics:
  - 📊 **Transaction Volume**: Total transaction count over the years
  - 💰 **Transaction Value**: Sum of transaction amounts by year
  - 🌍 **Regional Insights**: Transactions by state and region
  - 🗺️ **Geospatial Trends**: Transaction density across India
  - 📈 **Yearly Growth**: Trends in digital payments over time
- Provide **interactive filtering** for deeper insights
- Enable **data-driven decision-making** for stakeholders

## 👥 Target Audience
- **Business Executives**: High-level trends and growth insights
- **Policy Makers**: Digital adoption and financial inclusion trends
- **Data Analysts & Researchers**: Transaction patterns across regions

## 🚀 Key Features
- **📈 Intuitive Visuals**: Line charts, bar graphs, pie charts, and KPI cards
- **🌍 Geographic Analysis**: State-wise transaction heatmap
- **📊 Segmented Views**:
  - **Transaction Trends**: Growth in transaction count and amount over years
  - **State-wise Analysis**: Top-performing states based on transactions
  - **Regional Breakdown**: Transaction distribution by region
  - **Quarterly & Yearly Filters**: Interactive slicers for data exploration
- **📂 Export Options**: Share reports with stakeholders

## 📌 Expected Outcomes
✅ Understanding of transaction trends and adoption rates  
✅ Insights into regional transaction behavior  
✅ Data-driven strategies to enhance digital payment penetration
